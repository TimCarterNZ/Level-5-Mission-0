# Marketing Association NZ — Homepage Prototype

A responsive homepage prototype inspired by the Marketing Association of New Zealand, built using React and CSS.

## About the Project

The website is a responsive wireframe for Marketing Association of New Zealand's news site, and includes a navigation header, hero section, search bar and three marketing news articles.

### Built With

- React
- Vite
- JavaScript / JSX
- CSS
- Google Fonts (Roboto and Lato)

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
    ```

2. Navigate into the project directory:

    ```bash
    cd YOUR-REPOSITORY
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Start the development server:

    ```bash
    npm run dev
    ```

5. Open the local URL provided in the terminal.

## Usage

The homepage includes:

- **Navigation:** Links to the Home and News sections.
- **Hero:** Background image, heading, tagline and search interface.
- **Latest News:** Three article cards linking to external articles.
- **Responsive Layout:** Three-column article layout on desktop, changing to a single column on mobile.
- **Animations:** CSS hover animations on buttons.

The website is currently a frontend prototype. Search, authentication and mobile navigation functionality have not yet been implemented.
